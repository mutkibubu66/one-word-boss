Entrants send exactly one word describing their boss. A judge model picks the funniest, truest word, and the best ranked words take the reward.

The word: **Micromanager** — the boss who has to approve the font size, the comma placement, and the exact shade of the slide background, then asks why the project is late.

## Run it

```sh
python3 main.py
```
